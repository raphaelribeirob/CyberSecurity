# SOC Detection Lab — planned

**Status: not implemented.** This is a learning plan, not evidence of professional SOC experience.

## Goal
In an isolated, explicitly authorized environment:
1. Install a SIEM (candidate: Wazuh).
2. Ingest benign sample Windows/Linux logs.
3. Generate a controlled, simulated security event.
4. Create a transparent rule and validate it with sample events.
5. Document investigation steps, false positives and limitations.

Completion requires real test results, dated sanitized evidence, reproducible configuration and an explanation of what the alert does **not** prove.
