# Cloud Security Lab — planned

**Status: no cloud resources have been provisioned.**

## Goal
Build a disposable AWS training environment demonstrating IAM least privilege, audit logging and secure configuration.

## Milestones
1. Document scope, threat model and spending limits.
2. Configure accounts/roles with minimum necessary access.
3. Enable relevant audit logs and verify events.
4. Demonstrate a controlled misconfiguration and its remediation.
5. Remove billable resources and verify cleanup.

Never commit cloud credentials, tokens, account IDs or customer information. Cloud resources can incur costs.
