# Cybersecurity learning roadmap

This is a flexible learning plan, not a guarantee of employment.

| Stage | Core skills | Evidence to produce |
| --- | --- | --- |
| Foundations | CIA triad, IP, TCP/UDP, DNS, HTTP(S), basic OS concepts | Explained traces from a localhost network lab |
| Security operations | Linux/Windows event logs, SIEM, investigation, MITRE ATT&CK | Reproducible detection and incident triage in a controlled lab |
| Cloud Security | IAM, AWS shared responsibility, least privilege, security logs | Secure lab architecture and verified controls |
| Employability | Technical English, writing, interviews, teamwork | Accurate reports and ability to reproduce findings |

## First 30 days
- Complete Cisco Introduction to Cybersecurity and explain core ideas in your own words.
- Learn host, IP, ports, TCP and HTTP.
- Run the network lab and document what you actually observed.
- Practice basic Git/GitHub.

## Following 60 days
- Develop Linux command-line and Windows logging fundamentals.
- Learn practical Python and investigate simulated local events.
- Study entry-level job descriptions for US companies accepting remote applicants in Brazil.

A project is marked **Completed** only after personal execution, validation, sanitized evidence and a clear statement of limitations.
