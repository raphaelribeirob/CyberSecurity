# Guia rápido — seu portfólio em CyberSecurity

Objetivo: desenvolver conhecimento real e criar evidências técnicas honestas para recrutadores internacionais.

## Primeira missão
1. Continue a Introdução à Cibersegurança da Cisco.
2. Instale Python 3.10+ e Wireshark a partir das fontes oficiais.
3. Abra o README em network-security-lab para conhecer o laboratório.
4. Em um terminal, execute o servidor local.
5. No Wireshark, selecione a interface de loopback do seu próprio computador.
6. Em outro terminal, execute o cliente e identifique o tráfego TCP/HTTP.
7. Execute os testes automatizados.
8. Escreva **suas próprias** observações em inglês no modelo docs/LAB_REPORT_TEMPLATE.md.

Nunca publique capturas brutas, credenciais ou dados pessoais. O laboratório só envolve seu próprio computador.

## Rotina
- Estude os fundamentos antes de avançar para ferramentas.
- Use o portfólio para demonstrar análise, não apenas código.
- Marque um projeto como concluído somente depois de executar e explicar os resultados.
