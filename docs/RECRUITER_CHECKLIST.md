# Reviewer checklist — technical portfolio integrity

A project should be called completed only when it includes:
- [ ] A specific security problem and authorized scope
- [ ] Architecture and prerequisites
- [ ] Reproducible procedures and source code/configuration
- [ ] Actual dated test outputs and personal analysis
- [ ] Sanitized evidence supporting conclusions
- [ ] Limitations, risks and next steps
- [ ] Clear technical writing in English
- [ ] No secrets, personal data or raw sensitive packet captures

Suggested LinkedIn headline while learning:

Cybersecurity Student | Data Science Background | Building Skills in Network Security, Security Operations & Cloud Security

Never claim paid experience, earned certifications or completed labs until verified.
