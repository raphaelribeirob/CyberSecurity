# Responsible security learning

This repository contains **defensive educational labs** for systems owned by the learner or tested with explicit permission.

- The example service binds to local loopback only, not the public internet.
- Do not scan, intercept, test or capture third-party systems or traffic without authorization.
- Do not publish secrets, cloud account IDs, private data, raw packet captures or unsanitized screenshots.
- Use responsible disclosure channels for any real vulnerability discovered.
- If a secret is exposed, remove it from the project and rotate it; deleting a commit alone is insufficient.
- Findings produced by simulated exercises are not claims about real-world security incidents.
